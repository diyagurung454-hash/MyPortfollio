My Projects

Project 1: Rock Paper Scissors Game

I developed a simple Rock Paper Scissors game in C as a console-based project. The game allows the player to choose Rock, Paper, or Scissors and compares the choice with the computer's randomly generated choice. It includes options to play the game, view scores, and exit. I also used a score.txt file to save and display the scores. This project helped me improve my understanding of C programming, loops, conditions, functions, and file handling.

Project 2: Student Management Database

I developed a simple student management system using MySQL for database operations. The system allows for adding, updating, and deleting student records, as well as viewing all student information. This project helped me understand database design, SQL queries, and the integration of a database with a programming language.

Project 3: Basketball Live-Streaming App UI/UX

I designed a Basketball Live-Streaming App UI/UX focused on providing basketball fans with an easy and engaging way to watch live games. The design includes features such as live scores, game schedules, team information, and video streaming. I created the interface in Figma, focusing on simple navigation, clear layouts, and a user-friendly experience. This project helped me improve my skills in UI/UX design, wireframing, prototyping, and user-centered design.

Project 4: Networking Projects

Networking projects using Cisco Packet Tracer and Wireshark, focusing on network configuration and analysis.
